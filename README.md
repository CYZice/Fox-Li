## 源码运行

在项目根目录执行：

```powershell
python -m pip install -r src/requirements.txt
python src/demo.py
```

重新计算正式结果：

```powershell
$env:MPLBACKEND = "Agg"
python src/main.py
python src/bump.py
```

程序会生成图件和数据，重复运行会覆盖同名输出；生成的中间文件默认忽略。
